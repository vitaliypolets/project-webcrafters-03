# Definition of Done

Завдання вважається завершеним, коли:

- виконані обидві Frontend-фічі;
- працює Backend route;
- Frontend інтегрований із цим route;
- є валідація і коректні HTTP-статуси;
- є loading, error та empty state;
- адаптивність перевірена на 320, 375, 768 і 1440 px;
- `npm run lint` проходить;
- `npm run build` проходить;
- PR має інструкцію перевірки;
- зауваження Team Lead виправлені;
- код об’єднано в `develop`.
